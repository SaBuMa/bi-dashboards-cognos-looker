# 📐 KPI Catalog

A single definition for every metric on the dashboards. If two people build the same KPI in two tools, this is the reference they both follow. That is how the Cognos and Looker Studio dashboards ended up with identical numbers.

Each KPI's SQL lives in [`sql/dashboard_queries.sql`](../sql/dashboard_queries.sql) under the listed query name.

| KPI | Business definition | Formula | Source table | Format | Value | Query |
|---|---|---|---|---|---:|---|
| **Profit** | Total profit across all dealers, models and months | `SUM(profit)` | `AU_Sales_By_Model` | Currency USD, millions, 1 dp | $78.4M | `sales_p1_total_profit` |
| **Quantity Sold** | Total vehicles sold | `SUM(quantity_sold)` | `AU_Sales_By_Model` | Integer, thousands separator | 58,118 | `sales_p2_quantity_sold` |
| **Quantity Sold by Model** | Vehicles sold per model | `SUM(quantity_sold) GROUP BY model` | `AU_Sales_By_Model` | Integer | Hudson 20,365 … Champlain 2,896 | `sales_p3_quantity_by_model` |
| **Average Quantity Sold** | Average vehicles sold per model, per dealer, per month | `AVG(quantity_sold)` | `AU_Sales_By_Model` | 2 dp | 19.37 | `sales_p4_avg_quantity` |
| **Profit by Dealer** | Profit generated by each dealership | `SUM(profit) GROUP BY dealer_id` | `AU_Sales_By_Model` ⨝ `AU_Dealers` | Currency USD | $6.15M – $9.60M | `sales_p5_profit_by_dealer` |
| **# of Recalls (recalled units)** | Vehicles covered by recall campaigns, per model | `SUM(units) GROUP BY model` | `AU_Car_Recalls` | Integer, compact (303K) | Beaufort 303K … Salish 210K | `service_p1_recalls_by_model` |
| **Customer Sentiment** | Number of reviews per sentiment class | `COUNT(*) GROUP BY sentiment` | `AU_Sentiment` | Integer + % of total | Positive 58.6% | `service_p2_sentiment` |
| **Quantity Sold & Profit by Month** | Seasonality: totals per calendar month, all years combined | `SUM(quantity_sold)`, `SUM(profit) GROUP BY month` | `AU_Sales_By_Model` | Integer / currency, 2 axes | Peak: May | `service_p3_monthly_qty_profit` |
| **Recalls by Model × System** | Recalled units per model and affected system | `SUM(units) GROUP BY model, system_affected` | `AU_Car_Recalls` | Compact (70.4K), heat-map colour scale | Max: Beaufort × Airbag | `service_p4_recall_heatmap` |

## Definition notes

- **Average Quantity Sold depends on grain.** 19.37 is the average per *record* (model × dealer × month). Per dealer-month it would be 96.9; per month, 968.6. The KPI title should state its grain so viewers don't misread it.
- **"# of Recalls" counts vehicles, not campaigns.** The dataset's `Units` column is the number of vehicles covered. The campaign count is 163 in total (32–33 per model). See [data issue #3](../data/README.md#5-known-data-quality-issues).
- **All-time vs. filtered.** All values above are across the full date range of each table. Neither dashboard applies a date filter.
